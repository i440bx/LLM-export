## Changes in LLM Export

The initial LLM Export fork makes the following project-level changes relative to the recovered ChatGPT Export 9.3.0 package:

- removes the unrelated default search-provider override and its Searchvane/Yahoo configuration;
- renames the extension from ChatGPT Export to **LLM Export**;
- replaces product-name fallback strings with neutral LLM wording;
- updates extension metadata and privacy wording for independent distribution;
- adds licensing and attribution documentation for redistribution.
